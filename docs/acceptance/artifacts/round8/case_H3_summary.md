## TL;DR / 结论（标明置信度）

2026年9月19日（周六）拂晓，也门胡塞武装宣称对沙特首都利雅得的“敏感目标”和延布的沙特阿美（Aramco）设施发动了“大规模”导弹与无人机袭击并称“行动成功”；沙特主导多国联军则承认仅拦截了**一枚**射向利雅得的弹道导弹，并称对利雅得、比沙、塔伊夫、法拉桑和延布的其他袭击图谋“均被挫败”，无伤亡无损失。**双方在袭击规模、命中效果、延布是否受损上说法直接冲突，且多数关键战果声称目前无法独立核实**（置信度：高——事件发生本身有多方独立来源交叉证实；分歧细节的“不可确认”判断置信度亦为高，因路透/法新/美联社均明示无法核实）。

## Conclusions / 详细结论

1. **事件确凿发生**：这是自2026年7月沙特—胡塞冲突升级以来，利雅得**首次**拉响防空警报；沙特全境连夜通过手机推送“敌对空中威胁”紧急警报，周六上午解除 [1][2]。利雅得居民听到爆炸声、机场附近出现大火与浓烟，有AFP记者现场目击 [2]。
2. **叙事框架对立**：胡塞将其定性为对沙特一周内约300次空袭也门（含萨那）的报复性打击，宣称“两次成功军事行动”；沙特将其定性为对“平民及民用基础设施”的袭击，并强调自身的拦截成功与零损失 [1][2]。
3. **唯一经双方/多方印证的“硬事实”**：一枚射向利雅得的弹道导弹于拂晓被沙特皇家防空部队拦截摧毁（沙特联军发言人图尔基·马利基官方声明，新华社、法新、半岛电视台均报道）[1][3][4]。利雅得机场（哈立德国王国际机场）附近一处带阿美标志的储油罐起火，后被扑灭（AFP记者目击+视频核实）[2]。
4. **背景升级态势属实**：7月初以来冲突为2022年4月停火以来最激烈；胡塞已控制曼德海峡咽喉佩里姆岛；联合国称新一轮战斗已致超过11.2万人流离失所、近3000人渡海逃往吉布提 [1][2]。也门境内同日在马里卜、塔伊夫、拉赫季等地激战继续 [1]。
